# VROOMILLION

An 8-bit trivia racer. Every question has lots of right answers; the more niche yours is, the further your car goes. Earn cash, buy faster cars.

The game lives in `public/vroomillion/`; the site's home page (`/`) redirects there. `src/` is the Cloudflare Worker that handles accounts and payments.

## Where it runs
- **Vercel** (project `crazycobras-io`, https://vroomillion.vercel.app; the old crazycobras-io.vercel.app address still works) serves the game's files from `public/` with the same security headers as `public/_headers` (`vercel.json`). `api/proxy.js` forwards `/api/vroomillion/*` to the Worker (`WORKER_URL`), passing the player's IP in `x-client-ip` with `PROXY_SECRET`, so the Worker's rate limits count each player, not Vercel's servers.
- **Cloudflare Worker** `crazycobras-io` (https://crazycobras-io.nucleargames8856.workers.dev) runs the API: accounts in the `vroomillion` D1 database, payments, the live answer check and rate limits. `npx wrangler deploy -c wrangler.api.jsonc` deploys it without the static files; plain `npx wrangler deploy` deploys the files too, so the workers.dev address also serves the game.
- **Settings:** the Worker's plain variables are in `wrangler.jsonc` (`TURNSTILE_SITE_KEY`, `ALLOWED_ORIGINS`, which must list the Vercel address). Secrets live in the Cloudflare dashboard: `STRIPE_SECRET_KEY`, `TURNSTILE_SECRET`, `PROXY_SECRET`. On Vercel: `WORKER_URL`, and `PROXY_SECRET` (the same value as the Worker's).
- **Turnstile:** the widget (Cloudflare dashboard → Turnstile) must list every address the game runs on.
- Both run on free plans.

## How it works
- **Modes:** 1P is a solo run — your distance is your score; or 2P on one screen (answers are hidden while typing).
- **Question modes:** CLASSIC (all topics) or GEARHEAD (cars and racing only), picked on the race setup screen.
- **Live answer check:** an answer that isn't on a prompt's list is looked up on Wikidata by `POST /api/vroomillion/check` (`src/check.js`). It counts if the item found is the right kind of thing for the prompt; the rules are in `src/answer-classes.js`, generated with `node tools/build-answers.mjs --classes` from the same sources as the answer lists. Found answers score CRUISING to DEEP CUT by how widely they're covered, never ONE IN A VROOMILLION. Rate limited by `CHECK_LIMITER` (150 a minute per IP) and cached for a day. In the artifact preview there's no server, so the check finds nothing.
- **Generated prompts:** `tools/prompt-sources.mjs` defines hundreds of whole prompts (cities by country, songs by artist, films by director or actor, animals by family, teams by league, ...). `node tools/build-answers.mjs --prompts` builds `public/vroomillion/js/data-gen.js`, tiering each prompt's answers by how widely covered they are.
- **Answers:** close typos are offered as a fix (shown while typing in CLASSIC, after Enter elsewhere) and Enter again uses it; extra words in front still count ("front bumper" counts as bumper); wrong answers can be retried until the timer runs out.
- **Rarity tiers:** Stalled → Traffic → Cruising → Fast Lane → Deep Cut → One in a Vroomillion.
- **Free races:** 2 solo CLASSIC races a day per device (`FREE_RACES` in `logic.js`, counted in the browser). 2P VERSUS, GEARHEAD, HARD MODE and more races need Unlimited. `FREE_PLAY = true` lifts every limit.
- **No repeats:** each browser remembers every prompt it has shown (marked as each round starts, so quitting early doesn't use up the rest) and never shows it again. The setup screens show how many new prompts are left; a mode's last race uses whatever is left, and when a mode is used up its start button locks. **REDO THIS RACE** on the results screen replays the same prompts in the same order. New prompts added to `data.js` become playable automatically.
- **Answers:** each prompt's hand-written lists (in `data.js` / `data-pop.js`) are topped up with extra accepted answers: `data-extra.js` is generated by `tools/build-answers.mjs` from Wikidata and Wikipedia list pages (rarity comes from how many Wikipedia language editions cover the item), and `data-more.js` holds hand-written extras where Wikidata is weak. About 100,000 accepted answers in total. List pages are filtered: links must be the right kind of thing on Wikidata (`require`), or not a place, person, language, organisation, event or period; very widely covered generic links are dropped. Parallel builds: `--only "A;B" --out tools/.partN.js`, then `--merge tools/.part*.js`. Hand-written tiers always win, extra answers only go in CRUISING to DEEP CUT, and One in a Vroomillion stays hand-picked. Rebuild with `NODE_USE_ENV_PROXY=1 node tools/build-answers.mjs` (or `--only "Name a job;Name a bird"`, or `--refilter` to re-apply filters without fetching). Sources and per-prompt filters are in `tools/answer-sources.mjs`.
- **Prompts:** about 430 broad CLASSIC prompts (hand-written in `data.js`, `data-pop.js`, `data-hand2/3/4.js`, plus Wikidata-built ones in `data-gen.js`), the niche ones in HARD MODE, and GEARHEAD car prompts. `makeVariants` in `logic.js` makes "starting with M" twists, which only appear in HARD MODE and GEARHEAD. A prompt this device has seen never comes back; a race never uses two prompts from the same category if it can avoid it. If someone plays them all, a START THE PROMPTS OVER button lets them choose to repeat. Adding more hand-written prompts is the best way to grow the game.
- **One in a Vroomillion:** each question has only its rarest few answers in the top tier, and a fixed typo scores the same as the real answer. The end-of-round hint shows a Deep Cut, never a Vroomillion answer.
- **Admin:** accounts whose email is in the `ADMIN_EMAILS` Worker secret (comma separated) always have Unlimited and get an ADMIN screen (ACCOUNT → ADMIN): accounts, Unlimited and paid counts, races per day (counted anonymously by `POST /api/vroomillion/race-start`), and per player: give or remove Unlimited, and give today's free races back. API in `src/admin.js`.
- **Unlimited ($5, one-time, non-refundable):** removes the daily limit and unlocks 2P, GEARHEAD and HARD MODE. Buyers must create an account (email + password) first; Unlimited belongs to the account and works on any device they log in on. Paid through Stripe Checkout; see setup below.
- **Accounts:** stored in a Cloudflare D1 database (`DB` binding, created automatically on the first deploy). Passwords are salted PBKDF2-SHA256 hashes; sessions are HttpOnly cookies. Accounts are for players 13+. Each account gets a one-time **recovery code** at sign-up (stored only as a hash) that resets a forgotten password from the log-in screen; players can make a new code from the ACCOUNT screen. Players can delete their account in the game. Terms: `public/vroomillion/terms.html`; privacy notice: `public/vroomillion/privacy.html`.
- **Sound:** sound effects only, no music.
- **Adding questions:** edit `public/vroomillion/js/data.js`. Each question is five lists of answers, from most obvious to most niche; `"a|b"` makes `b` an accepted spelling of `a`. Add `deck: "car"` for GEARHEAD-only questions or `deck: "both"` for questions in both modes.
- **Adding cars:** edit the `CARS` list in `public/vroomillion/js/cars.js`.
- **Tests:** `npm test` covers answer judging, scoring, the daily limit, the question data and the payment endpoints.
- Font: Press Start 2P (SIL Open Font License, see `public/vroomillion/fonts/OFL.txt`).

## Turning on the $5 Unlimited payment
The game asks the Worker (`src/vroomillion.js`) to open a Stripe Checkout for the logged-in account, and after payment confirms with Stripe that it really went through before marking that account Unlimited. If a buyer closes the tab before coming back, the account is upgraded the next time they open the game. Until the key below is set, the buy button just says payments aren't set up — nobody can be charged.

1. The Worker and its `vroomillion` D1 database are already set up; the tables are created on first use.
2. **Stripe dashboard** → Developers → API keys → **Create restricted key**. Give it **Checkout Sessions: Write** and nothing else. Copy it. Start with a **test-mode** key (`rk_test_…`).
3. **Cloudflare dashboard** → Workers & Pages → `crazycobras-io` → Settings → Variables and Secrets → Add → type **Secret**, name `STRIPE_SECRET_KEY`, value = the key → Deploy. Never put the key in the repo.
4. Open the game, use your free run, press **GO UNLIMITED**, and pay with Stripe's test card `4242 4242 4242 4242` (any future date, any CVC). You should land on "UNLIMITED UNLOCKED!".
5. When that works, replace the secret with a **live** restricted key (`rk_live_…`) to take real money.

Buyers see the Stripe account's **business name** on the checkout page and on their card statement, so use an account that is yours and named for the game.

### Limits to know about
- Unlimited is checked on the server against the account, so it can't be faked in the browser. The one-free-run-a-day limit for players without Unlimited is still kept in the browser; clearing site data gives a fresh free run.
- Password reset works with the recovery code, not email (that would need an email service). A buyer who loses both the password and the code can be helped by hand: check their payment in Stripe, ask them to make a new account, and mark it Unlimited in the D1 console with `UPDATE users SET unlimited = 1 WHERE email = '…'`.
- The site doesn't show a contact email yet. The Terms send buyers to the support contact on their Stripe receipt, so set a support email in Stripe → Settings → Business → **Public details** before going live.
- **No refunds.** The Terms say all sales are final, and buyers must tick "I understand Unlimited starts right away and is non-refundable" before checkout; the server refuses checkout without it and records the time on the Stripe payment (`metadata.no_refund_accepted_at`) as evidence if a buyer disputes the charge. If you ever do refund someone, set `unlimited = 0` for that account in D1.
- Password hashing uses 50,000 PBKDF2 rounds so sign-ups fit the Workers free plan's CPU limit. On a paid plan, set the variable `PBKDF2_ITERATIONS` to `100000`; existing passwords upgrade when people next log in.
- Accounts and payments only work on the website, not in the Claude artifact preview.
